# Import Data Using Transform Maps (Spreadsheet)

**Team ID:** SWTID-2026-2183  
**Platform:** ServiceNow (Import Sets, Data Sources & Transform Maps)

## Project Overview
This repository contains the phase-wise documentation and implementation evidence for importing spreadsheet data into ServiceNow using Import Sets and Transform Maps. The project covers creating a data source from a spreadsheet, loading it into a staging (import set) table, building a transform map with field mappings, running the transform with coalesce enabled to prevent duplicate records, and finally presenting the imported data through reports and dashboards.
